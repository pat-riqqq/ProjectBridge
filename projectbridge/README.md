# ProjectBridge public prototype
1. Buat akun GitHub dan Vercel.
2. Buat repository GitHub baru bernama `projectbridge`.
3. Upload `index.html` ke root repository.
4. Di Vercel pilih Add New → Project, impor repository tadi.
5. Framework Preset pilih Other, lalu klik Deploy.
6. Vercel akan memberikan URL publik.

Batasan: ini front-end prototype. Belum ada autentikasi, database bersama, pembayaran, atau penyimpanan data server. Data contoh dan perubahan hanya berlaku di browser pengguna. Jangan gunakan untuk transaksi sungguhan atau mengumpulkan data pribadi.
